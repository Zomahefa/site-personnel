Le bloc contact contient les libellés de la colonne de gauche et tous les textes du formulaire. Les champs eux-mêmes sont dans src/components/site/contact-form.tsx ; les textes sont dans contact.form.

5.12 Textes de l’assistant IA

Deux endroits distincts :

  1. content.ts → ai : les textes visibles du widget (titre, accueil, suggestions, erreurs, disclaimer).
  2. src/lib/assistant-prompt.ts : les règles et le contexte envoyés au modèle (ton, périmètre, profil, projets, stack…).
Mise à jour automatique du contexte

Le prompt est construit à partir de defaultContent (le français). Si vous modifiez un projet, une expérience ou une certification dans content.ts, l’assistant apprendra l’information au prochain build, sans toucher à assistant-prompt.ts. Vous ne modifiez ce fichier que pour changer les règles ou le ton.

5.14 SEO, métadonnées et partage

Le titre et la description globaux

Dans src/app/layout.tsx : 

const title = "Zo Mahefa RANAIVO — Développeur web, DevOps & QA";
const description = "Portfolio de Zo Mahefa RANAIVO, développeur web & mobile...";

Le template de titre ajoute automatiquement « — Zo Mahefa RANAIVO » aux pages qui définissent leur propre titre (comme l’admin).

Les autres champs à connaître

ChampEffet
metadataBaseBase des URLs absolues pour Open Graph et Twitter. Dépend de siteUrl.
keywordsMots-clés (peu utilisés par Google, utiles pour d’autres moteurs).
alternates.canonicalURL canonique de la page d’accueil.
openGraphTitre, description, image 1200×630, locale fr_FR.
twitterCarte summary_large_image.
robotsIndexation et directives Googlebot.
verification.googleCode de vérification Search Console. Le fichier HTML de vérification est aussi dans public/.
schema (JSON-LD)Décrit la personne, le site et la page de profil pour les moteurs.

Changer de domaine

  1. Ajoutez le domaine dans Vercel (Settings → Domains).
  2. Configurez les enregistrements DNS demandés.
  3. Mettez NEXT_PUBLIC_SITE_URL à la nouvelle URL, sans slash final.
  4. Redéployez.
  5. Vérifiez /sitemap.xml, /robots.txt et le code source (canonical, JSON-LD).
  6. Demandez à Google Search Console de réindexer, et rafraîchissez l’aperçu LinkedIn.

Le JSON-LD

Le JSON-LD décrit Person, WebSite et ProfilePage. Il contient le nom, les rôles, la photo, l’e-mail, le téléphone, l’adresse, les réseaux, l’école, les langues et les compétences. Si vous changez de nom, de téléphone ou de réseau social, mettez à jour site et le JSON-LD de layout.tsx (certaines valeurs y sont encore écrites en dur).

5.15 Vérifier après chaque modification

  • La même clé a été modifiée dans fr et dans en.
  • npm test passe (parité FR/EN, aucun texte vide).
  • npm run build passe (TypeScript, imports, routes).
  • Le rendu local est correct en français et en anglais.
  • Les liens ajoutés répondent (GitHub, démo, PDF).
  • Les images ajoutées sont dans public/ avec un nom en minuscules.
  • Le texte ne contient pas de secret ni de donnée personnelle non autorisée.
  • Le commit est poussé : Vercel redéploie automatiquement.
