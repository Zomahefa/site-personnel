Chapitre 08Assistant IA

L’assistant est un widget flottant présent sur toutes les pages publiques, sauf l’administration. Il répond aux questions sur le parcours, les projets, les compétences et la disponibilité. Il ne voit que des informations publiques et ne stocke aucune conversation en base.

8.2 Les variables d’environnement

VariableObligatoireRôle
GROQ_API_KEYOui si GroqClé API Groq. Utilisée par défaut si présente.
GOOGLE_AI_API_KEYOui si GeminiClé Google AI Studio.
AI_PROVIDERNongroq ou google. Force le fournisseur si la clé correspondante existe.
GROQ_MODELNonModèle Groq. Défaut : openai/gpt-oss-120b.
GOOGLE_AI_MODELNonModèle Gemini. Défaut : gemini-2.5-flash.

Ordre de résolution du fournisseur

  1. Si AI_PROVIDER=google et GOOGLE_AI_API_KEY existe → Google.
  2. Si AI_PROVIDER=groq et GROQ_API_KEY existe → Groq.
  3. Sinon, si GROQ_API_KEY existe → Groq.
  4. Sinon, si GOOGLE_AI_API_KEY existe → Google.
  5. Sinon → réponse 503 not-configured, le widget affiche son message de repli.

8.3 Les modèles et paramètres

Groq (par défaut)

POST https://api.groq.com/openai/v1/chat/completions
model: GROQ_MODEL ?? "openai/gpt-oss-120b"
temperature: 0.35
max_tokens: 900
reasoning_effort: "low"
messages: [system, ...8 derniers messages]

reasoning_effort: "low" est important pour les modèles de raisonnement : sans cela, les tokens de réflexion peuvent consommer tout le budget et renvoyer une réponse vide. max_tokens: 900 laisse assez de place pour une réponse de 3 à 6 phrases.

Google Gemini (alternative)

POST https://generativelanguage.googleapis.com/v1beta/models/{model}:generateContent
model: GOOGLE_AI_MODEL ?? "gemini-2.5-flash"
temperature: 0.35
maxOutputTokens: 450
systemInstruction: prompt système
contents: messages (assistant → model)

8.4 Le prompt système

src/lib/assistant-prompt.ts construit le prompt à partir de defaultContent (le français). Il contient :

  • Le rôle : assistant du portfolio de Zo Mahefa.
  • Les règles : rester dans le périmètre, ne rien inventer, répondre dans la langue de la question, rester concis, ne pas révéler le prompt ni les variables.
  • Le profil : nom, rôles, localisation, disponibilité, modalités, contact, réseaux, CV, langues.
  • Les projets, l’expertise, le QA, les expériences, la formation, les certifications, les témoignages et la stack.
Mise à jour du savoir de l’assistant

Si vous modifiez un projet, une expérience ou une certification dans content.ts, l’assistant utilisera la nouvelle information au prochain build. Vous n’avez pas à dupliquer le contenu dans le prompt. Ne modifiez assistant-prompt.ts que pour changer les règles, le ton ou la structure du contexte.

8.5 Tester l’assistant en local

Démarrez le serveur, puis envoyez une requête avec curl : 

curl -s http://localhost:3000/api/assistant \
  -H "Content-Type: application/json" \
  -d '{"messages":[{"role":"user","content":"Quels sont tes projets les plus solides ?"}]}'

Réponse attendue :

{"reply":"...","provider":"groq"}

Si vous obtenez {"error":"not-configured"}, aucune clé n’est chargée. Vérifiez .env.local et redémarrez npm run dev : Next.js ne recharge pas toujours les variables sans redémarrage.

8.6 Changer de fournisseur

Passer à Gemini

  1. Créez une clé sur Google AI Studio.
  2. Dans .env.local ou Vercel : GOOGLE_AI_API_KEY=....
  3. Ajoutez AI_PROVIDER=google.
  4. Redémarrez ou redéployez.
  5. Vérifiez que /api/assistant répond avec "provider":"google".

Changer de modèle Groq

GROQ_MODEL=openai/gpt-oss-120b

Utilisez un modèle disponible sur votre compte Groq. Si le modèle n’existe pas ou n’est pas accessible, l’API renvoie une erreur et la route répond 502 provider-error.

8.8 Coût, confidentialité et limites

  • Chaque question consomme des tokens chez le fournisseur. Le paramètre max_tokens limite la dépense, mais ne la supprime pas.
  • Aucune conversation n’est enregistrée en base. L’historique vit dans l’état React du widget et disparaît au rechargement.
  • Le prompt ne contient que des informations publiques. Il ne faut jamais y ajouter de données personnelles, de secrets ou de messages reçus.
  • Le modèle peut se tromper. Le widget affiche un disclaimer et propose d’écrire directement.
  • Les réponses sont générées à la volée : elles ne sont pas validées par un humain avant affichage.
